OPEN MASTERING STUDIO {VERSION} - Linux x86-64 (BETA)
=====================================================

This is an experimental Linux build. It is the same Open Mastering Studio as
the Windows release, built natively for Linux. It passes the full automated
test suite and loads in Ardour, but it has not yet been tried widely on real
Linux systems. Please tell us how it works for you (see "Feedback" below).

Contents
--------
  VST3/Open Mastering Studio.vst3     The VST3 plugin (a folder - keep it whole)
  LV2/Open Mastering Studio.lv2       The LV2 plugin (a folder - keep it whole)
  Standalone/Open Mastering Studio    The standalone app (runs from anywhere)
  install.sh                          Copies both plugins into your home folder
  README.md                           Full manual: signal chain, meters, presets, export
  MEASUREMENTS.md                     Measured distortion, aliasing, true peak, latency, CPU

Requirements
------------
64-bit Intel/AMD Linux with glibc 2.38 or newer (Ubuntu 24.04, Debian 13,
Fedora 39, Linux Mint 22 or later), X11 or XWayland, and ALSA, JACK or
PipeWire for audio. The plugins work in any VST3 or LV2 host, for example
Ardour, Reaper, Bitwig Studio, Carla or Qtractor.

Install the plugins
-------------------
Option A: open a terminal in this folder and run
    ./install.sh
It copies the plugins to ~/.vst3 and ~/.lv2 (no administrator rights needed)
and replaces an older version if there is one.

Option B: copy the folders by hand:
    "Open Mastering Studio.vst3"  into  ~/.vst3/
    "Open Mastering Studio.lv2"   into  ~/.lv2/

Then rescan plugins in your DAW. Insert Open Mastering Studio last on your
stereo master bus. It reports its latency (about 7.5 ms; about 90 ms more for
each linear-phase option), so the DAW compensates. Use either the VST3 or the
LV2, not both on one track: they sound the same.

Use the standalone app
----------------------
Run Standalone/Open Mastering Studio (double-click it, or start it from a
terminal). If your file manager opens it as a file, right-click it and make
it executable, or run: chmod +x "Standalone/Open Mastering Studio"
  1. Choose your audio output under Options > Audio/MIDI Settings...
     (ALSA "default" goes through PulseAudio/PipeWire; or use JACK).
  2. Click Open..., or drag a WAV / AIFF / FLAC / MP3 / OGG file onto the window.
  3. Shape the master while it plays, then choose a format and click Export Master...

Uninstall
---------
Delete ~/.vst3/Open Mastering Studio.vst3, ~/.lv2/Open Mastering Studio.lv2
and the app. Your presets are kept in ~/Documents/Open Mastering Studio/Presets
(or your language's Documents folder).
