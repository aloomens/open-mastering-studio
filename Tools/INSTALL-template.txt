Install the VST3 plugin
-----------------------
Option A: Double-click "Install VST3.bat" and click Yes when Windows asks for
administrator permission.

Option B: Copy the whole "Open Mastering Studio.vst3" folder from the VST3 folder into
    C:\Program Files\Common Files\VST3

Then rescan plugins in your DAW. Insert Open Mastering Studio last on your
stereo master bus. It reports its latency (about 7.5 ms; about 90 ms more for
each linear-phase option), so the DAW compensates.

Use the standalone app
----------------------
Run Standalone\Open Mastering Studio.exe from anywhere (Desktop, USB stick, etc.).
  1. Click Open..., or drag a WAV / AIFF / FLAC / MP3 / OGG file onto the window.
  2. Shape the master while it plays.
  3. Choose a format and click Export Master...

untick "Mute audio input".

Upgrading from Mastering Studio (1.7.5 and earlier)
---------------------------------------------------
It is the same plugin under a new name. Your DAW sessions load it as before,
and your saved presets are copied to the new folder automatically. Install
VST3.bat removes the old "Mastering Studio.vst3" so the plugin isn't listed
twice; if you install by hand, delete the old folder yourself. The standalone
app starts with default audio settings once; choose your audio device again
under Options > Audio/MIDI Settings.

Uninstall
---------
Delete C:\Program Files\Common Files\VST3\Open Mastering Studio.vst3 and the .exe.
Your presets are kept in Documents\Open Mastering Studio\Presets.
